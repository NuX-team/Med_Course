# MedCourse

Telegram-бот контроля курсов лекарств: врач оформляет план приёма, пациент начинает курс кнопкой,
получает напоминания и отмечает приём. MVP — Узбекистан, частные врачи.

Сервис организует назначенное врачом лечение; диагнозов не ставит и схему не меняет.
