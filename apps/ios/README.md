# MedCourse для iPhone

Нативное приложение на SwiftUI (iOS 17+). Пациент видит приёмы на сегодня, свои курсы и историю, отвечает на приёмы
(«выпил», «пропустить», «позже»). Напоминания по-прежнему приходят в Telegram-бот: приложение — второй вход в тот же
аккаунт, а не замена бота. Данные общие: что отмечено в приложении, видно в боте, и наоборот.

## Запуск на своём iPhone

1. Mac с **Xcode 15.4+** (бесплатно в App Store).
2. `git clone https://github.com/NuX-team/Med_Course.git && cd Med_Course && git checkout feat/ios-app`
3. Открыть `apps/ios/MedCourse.xcodeproj`.
4. Xcode → Settings → Accounts → добавить свой Apple ID.
5. Цель **MedCourse** → Signing & Capabilities → Team = свой Apple ID. Если Xcode ругается на Bundle Identifier —
   поменять `uz.medcourse.app` на любой свой, например `uz.medcourse.farhod`.
6. Подключить iPhone кабелем, выбрать его вверху, нажать ▶︎.
7. На iPhone: Настройки → Основные → VPN и управление устройством → доверять своему профилю разработчика.

С бесплатным Apple ID приложение живёт на телефоне 7 дней, потом снова ▶︎ из Xcode. С платным аккаунтом ($99/год)
ограничения нет и можно раздавать через TestFlight.

## Куда приложение ходит

| Сборка  | Адрес API                  | Где задаётся                              |
| ------- | -------------------------- | ----------------------------------------- |
| Debug   | `http://localhost:3003`    | `API_BASE_URL` в `tools/gen_xcodeproj.py` |
| Release | `https://api.medcourse.uz` | там же                                    |

Имя бота для входа — `BOT_USERNAME` там же; сервер берёт его из `TELEGRAM_BOT_USERNAME`. Для проверки на телефоне Debug
нужно направить на адрес, который телефон видит (сервер с HTTPS или Mac в той же сети).

## Как устроен вход

Без пароля и SMS. «Войти через Telegram» → приложение просит у API ссылку `t.me/<бот>?start=a_<код>` → человек нажимает
в боте «Подтвердить вход» → приложение, которое всё это время спрашивало API, получает токен. Токен лежит в Keychain,
на сервере — только его хэш. Войти может только зарегистрированный в боте пациент.

## Файлы

```
MedCourse/Core     модели, сетевой клиент, тексты ru/uz, форматирование — без UIKit, проверяется на Linux
MedCourse/UI       экраны SwiftUI: вход, Сегодня, Курсы, курс, история, профиль, согласие и данные
CoreCheck          проверка Core на ответах настоящего API (fixtures — снятые с тестовой базы)
tools/             генератор .xcodeproj и иконки
```

`.xcodeproj` генерируется: добавив файл в `MedCourse/`, запустить `python3 apps/ios/tools/gen_xcodeproj.py` и
закоммитить оба. CI (`.github/workflows/ios.yml`) проверяет, что проект совпадает с исходниками, и собирает приложение
на macOS.
